## Built in the open

Ryoku is a community-first passion project led by [neur0map](https://github.com/neur0map), with the NixOS port maintained by [aethctl](https://github.com/aethctl) and contributors.  
There is no large company behind it — just people building something they believe is worth existing.

For project structure and stewardship, see [governance](https://github.com/Ryoku-dev/.github/blob/main/GOVERNANCE.md).  
For private stewardship questions: [neuro@ryoku.dev](mailto:neuro@ryoku.dev).
