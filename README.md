## Made with intention

Ryoku is a community-first, open-source Linux desktop project led by [neur0map](https://github.com/neur0map), built by maintainers in their spare time and improved by contributors. The goal is a desktop that feels considered from end to end, with its own shell, tools, installer and visual identity.

The main project brings that experience to **Arch Linux, CachyOS, Void Linux and Fedora**, with a separately maintained **NixOS port**. Editions have different levels of maturity and hardware support, so check their documentation before installing.

**A note on hardware:** Ryoku prioritizes a rich desktop experience on capable machines. It is not intended as a lightweight distribution for older or low-resource hardware.

## Ryoku on NixOS

[Ryoku on NixOS](https://github.com/Ryoku-dev/Ryoku-on-NixOS) is the recognized NixOS port, maintained by [aethctl](https://github.com/aethctl) and [contributors](https://github.com/Ryoku-dev/Ryoku-on-NixOS/graphs/contributors). It shares Ryoku's design direction while keeping its own NixOS-native implementation and maintainership. Installation instructions and support guidance live with the port.

| Project | What it does |
| :-- | :-- |
| **[Ryoku on NixOS](https://github.com/Ryoku-dev/Ryoku-on-NixOS)** | NixOS integration, desktop environment, installer and system configuration. |
| **[RyotunesNix](https://github.com/Ryoku-dev/RyotunesNix)** | NixOS-native packaging and integration for Ryotunes. |
| **[NixOS Documentation](https://github.com/Ryoku-dev/NixOS-Documentation)** | Guides and documentation for the NixOS port. |

## Built in the open

There is no large company or full-time engineering team behind Ryoku. Ideas, testing, documentation, bug reports and code all contribute to the project. We listen to our community, but what we can build and support depends on the time and resources available.

Ryoku is founder-led, with responsibilities delegated to maintainers. Read the [governance document](https://github.com/Ryoku-dev/.github/blob/main/GOVERNANCE.md) for how decisions and stewardship work. The organization is a place to collaborate, not a claim of nonprofit or charitable status.

We also build on the work of many upstream projects. Each repository retains its applicable licenses, copyright notices, contributor credits and fork history.

## Get involved

- **Contribute:** Start with the [contribution guide](https://github.com/Ryoku-dev/ryoku/blob/main/CONTRIBUTING.md) and [code of conduct](https://github.com/Ryoku-dev/ryoku/blob/main/CODE_OF_CONDUCT.md).
- **Test and report:** Open reproducible bug reports in the affected project's issue tracker, or help verify fixes and documentation.
- **Discuss:** Talk through larger proposals before investing in a major change.

For private project or stewardship questions, contact [neuro@ryoku.dev](mailto:neuro@ryoku.dev). For security vulnerabilities, use the affected repository's security policy rather than opening a public issue.
